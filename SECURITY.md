# Security Policy

## Scope

QUANTA2 is an experimental Arduino firmware and educational simulation project. It is not designed as a security product and must not be used for cryptography, authentication, safety-critical control, or security-sensitive randomness.

The current Watchdog/Timer1 mixing mechanism is not a certified entropy source.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue before maintainers have had a chance to assess the report.

Use GitHub's private vulnerability reporting for this repository, if enabled:

https://github.com/Vice13th/QUANTA/security/advisories/new

If private reporting is unavailable, contact the repository owner through the contact information on their GitHub profile and include:
- A concise description.
- Affected commit or file.
- Reproduction steps.
- Potential impact.
- A suggested mitigation, if known.

## Supported versions

Security fixes, if any, will be applied to the current default branch. No formal support or response-time SLA is currently offered.
