# Support

Before requesting help:

1. Read the [README](README.md).
2. Check the [Hardware Guide](docs/HARDWARE.md) for wiring and OLED detection.
3. Check the [Validation Plan](docs/VALIDATION.md) for known limitations and required evidence.
4. Search existing [issues](https://github.com/Vice13th/QUANTA/issues).

For a reproducible bug, open a GitHub issue and include the firmware commit, board model, OLED controller/address, Arduino CLI or IDE version, and relevant logs.

Please do not use this project for safety-critical, security-sensitive, or cryptographic applications.
